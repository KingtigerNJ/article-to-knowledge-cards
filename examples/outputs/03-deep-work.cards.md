# 知识卡片：为什么"深度工作"比"忙碌"更稀缺

（输入类型：观点 / 议论文章 · 6 张卡片）

### 卡片 1：核心论点——稀缺的是注意力而非时间
- **核心知识**：在知识经济中，真正稀缺的是不受打扰的注意力，而"深度工作"正变得越来越稀有、越来越有价值。
- **简明解释**：作者把在无干扰状态下专注进行认知密集型任务的能力称为"深度工作"。
- **例子 / 自测**：自测——作者认为知识经济中真正稀缺的资源是什么？

### 卡片 2：深度工作与浮浅工作的区分
- **核心知识**：深度工作需要高度专注、能创造新价值且难以复制；浮浅工作是事务性的、容易被替代的。
- **简明解释**：作者主张浮浅工作是必要的，但不应成为工作的主体，否则个人会逐渐失去处理复杂问题的能力。
- **例子 / 自测**：自测——按照作者的分类，"容易被替代"的是哪一类工作？

### 卡片 3：注意力被碎片化的机制
- **核心知识**：网络工具降低了沟通成本，使组织默认人们随时在线，从而把一天切碎。
- **简明解释**：频繁的邮件、会议和即时消息造成打断，而每次打断后重新进入专注都要付出可观的"注意力残留"成本。结果是人们看起来很忙，真正产出的成果却很少。
- **例子 / 自测**：自测——"注意力残留"成本指的是什么？

### 卡片 4：策略之一——固定日程生产力
- **核心知识**：为一天设定明确的结束时间，并禁止在结束时间之后继续工作。
- **简明解释**：这一约束会倒逼你在有限时间内砍掉浮浅任务，从而提高对深度工作的投入。
- **例子 / 自测**：自测——"固定日程生产力"为什么能反过来提升深度工作的投入？

### 卡片 5：策略之二——为深度工作安排固定时间块
- **核心知识**：为深度工作安排固定的时间块，并把它当作不可挪动的约会。
- **简明解释**：通过把深度工作预先占位到日程里，避免它被临时的浮浅事务挤出。
- **例子 / 自测**：自测——作者建议用什么样的态度对待深度工作的时间块？

### 卡片 6：适用边界——并非人人适用
- **核心知识**：深度工作并非对所有人都同样适用，关键在于有意识地选择把注意力投向哪里。
- **简明解释**：如果工作本身以协调、响应为主，强行追求长时间的深度状态可能并不现实。因此重点不是照搬方法，而是不被工具牵着走。
- **例子 / 自测**：自测——对于以协调、响应为主的工作，作者提醒了什么？
